# Internationalisation (FR/EN/AR + RTL)

Les principes complets sont dans
[`architecture.md` §G](./architecture.md#g-architecture-multilingue-frenar--rtl).
Ce document couvre ce qui est déjà en place.

## Fichiers

- `src/i18n/routing.ts` — langues, préfixe toujours présent dans l'URL
  (`localePrefix: "always"`), sens d'écriture par langue.
- `src/i18n/navigation.ts` — `Link`, `redirect`, `usePathname`, `useRouter`
  localisés (next-intl).
- `src/i18n/request.ts` — charge les messages ; `NAMESPACES` liste les
  fichiers de traduction chargés pour chaque requête.
- `src/proxy.ts` — résolution de la langue (remplace `middleware.ts` dans
  Next.js 16, voir `AGENTS.md` généré par Next).
- `messages/{fr,en,ar}/*.json` — un fichier par espace de noms (`common`,
  `public`, puis `auth`, `portal`, `admin`, `emails`, `documents`,
  `validation` au fur et à mesure des phases).

## Ajouter une page ou un texte

1. Ajoutez la clé dans les **trois** fichiers de langue (même structure).
2. Aucune chaîne visible ne doit être écrite en dur dans un composant —
   toujours `useTranslations` (client/serveur) ou `getTranslations` (Server
   Components asynchrones).
3. Si le namespace n'est pas encore chargé par une route, ajoutez-le à
   `NAMESPACES` dans `request.ts` (ou chargez-le plus finement par route
   quand ce sera nécessaire).

## RTL

- `<html dir>` est déterminé côté serveur dans
  `src/app/[locale]/layout.tsx` via `localeDirection` — jamais de bascule
  visible après hydratation.
- Utiliser uniquement des utilitaires Tailwind **logiques** :
  `ms-*`/`me-*`/`ps-*`/`pe-*`/`start-*`/`end-*`/`text-start`/`text-end`,
  jamais `ml-*`/`mr-*`/`left-*`/`right-*`/`text-left`/`text-right`.
- La police arabe (`IBM Plex Sans Arabic`) est appliquée automatiquement en
  RTL via `[dir="rtl"]` dans `src/styles/globals.css` — elle n'est chargée
  que sur les pages qui l'utilisent (`next/font` gère le sous-ensemble).
- Une icône directionnelle (flèche, chevron) doit prévoir son miroir en
  RTL (`rtl:-scale-x-100`) ; une icône non directionnelle (coche, croix,
  horloge) ne se retourne jamais.

## Vérifier

```bash
npm run build   # prérend /fr, /en, /ar (generateStaticParams)
```

Un contrôle visuel rapide (Playwright, capture d'écran de `/ar`) fait partie
de la routine de vérification avant de livrer une nouvelle page tant que la
suite de tests E2E (phase 12) n'existe pas encore.
